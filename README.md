# Network Security Lab (مختبر أمان الشبكات)

تطبيق أندرويد دفاعي أصلي (Native) متخصص في فحص وتشخيص أمان الشبكات المحلية المصرح باختبارها.
يعمل التطبيق محلياً بالكامل على الجهاز بدون خوادم خارجية، وبدون صلاحيات الروت (Root)، وبدون الحاجة لـ Termux.

---

## 🛡️ إخلاء المسؤولية القانونية (Legal Disclaimer)

> **تحذير قانوني هام:**
> استخدم هذا التطبيق فقط على الشبكات والأجهزة التي تملكها أو لديك تصريح رسمي وصريح لاختبارها وتدقيقها. أي استخدام غير مصرح به قد يُعد انتهاكاً للقوانين واللوائح المعمول بها. التطبيق صُمم كأداة دفاعية للقراءة والتشخيص فقط ولا يحتوي على أي كود استغلالي.

## 🛠️ متطلبات وطريقة البناء والتثبيت

### 1. المتطلبات
- **Android Studio** (Hedgehog أو أحدث).
- **JDK 17** أو أحدث.
- **Android SDK** مع إصدار SDK المنصة المناسب.

### 2. البناء (Build)
من سطر الأوامر في مجلد المشروع الرئيسي:
```bash
./gradlew assembleDebug
```
ينتج ملف الـ APK في المسار:
`app/build/outputs/apk/debug/app-debug.apk`

### 3. التثبيت (Install via ADB)
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 🔐 الصلاحيات المطلوبة وسببها

| الصلاحية | سبب الاستخدام في التطبيق |
| :--- | :--- |
| `android.permission.INTERNET` | إجراء فحوصات الاتصال والمقابس (Sockets, HTTP, DNS, Ping). |
| `android.permission.ACCESS_NETWORK_STATE` | التحقق من حالة الاتصال (Wi-Fi أو بيانات خلوية أو وضع عدم الاتصال). |
| `android.permission.ACCESS_WIFI_STATE` | قراءة بيانات اتصال Wi-Fi الحالية مثل BSSID وتردد الإشارة. |
| `android.permission.ACCESS_COARSE_LOCATION` / `ACCESS_FINE_LOCATION` | إلزامية في نظام أندرويد منذ Android 8.1 لقراءة اسم شبكة الـ Wi-Fi الحقيقي (SSID). |

## 📱 الأدوات المتاحة وطريقة استخدامها

1. **معلومات الشبكة (Network Info):**
   - تعرض عنوان الـ IP المحلي، البوابة الافتراضية (Gateway)، قناع الشبكة (Subnet Mask / CIDR)، خوادم DNS النشطة، واسم شبكة الـ Wi-Fi.

2. **اكتشاف الأجهزة (Device Discovery):**
   - تقوم بمسح متوازي (Parallel Sweep عبر 32 مسار متزامن) لكافة عناوين النطاق الفرعي المحلي.
   - تستخرج اسم الجهاز (Hostname)، العنوان الفزيائي (MAC Address)، واسم الشركة المصنعة (Vendor) من جدول ARP ومطابقة OUI.
   - تتيح نقرة واحدة للبدء المباشر في فحص منافذ أي جهاز مكتشف.

3. **فاحص المنافذ (Port Scanner):**
   - يدعم المنافذ الشائعة (14 منفذاً) وقائمة الأمان الموسعة (32 منفذاً) ونطاقات مخصصة (Custom Range مثل `1-1024`).
   - اتصال TCP Connect مباشر مع قياس زمن الاستجابة (Latency ms).
   - تمييز دقيق للحالة: **مفتوح (Open)**، **مغلق (Closed)**، **مُرشّح (Filtered)**.
   - يتضمن ميزة **Service Inspector** لقراءة ردود الخدمة الأولية (Banner Grabbing) وفحص شهادات SSL/TLS دون إرسال أي حمولات استغلالية.

4. **محلل HTTP / HTTPS:**
   - فحص واجهات الويب المحلية والخارجية.
   - قياس زمن الاستجابة وترويسات الرد الكاملة.
   - تدقيق تلقائي لترويسات الأمان (HSTS, CSP, X-Frame-Options, X-Content-Type-Options).
   - استخراج وتفصيل شهادة الـ TLS مع تحذير عند انتهاء الصلاحية أو الشهادات الموقعة ذاتياً.

5. **أدوات التشخيص (Tools):**
   - **Ping:** قياس زمن الاستجابة ونسبة فقدان الحزم (Packet Loss %) ومخرجات الطرفية.
   - **DNS Resolver:** استخراج سجلات النطاق وزمن التحليل.
   - **Traceroute:** تتبع مسار الحزم خطوة بخطوة بالقفزات (Hops).

6. **تقرير التدقيق الأمني (Security Audit Report):**
   - تجميع فوري للمخاطر وتصنيفها حسب الخطورة:
     - **مرتفع (High):** منافذ Telnet (23)، FTP (21)، SMB (445).
     - **متوسط (Medium):** HTTP (80) غير المشفر، منافذ إدارية (8080).
     - **منخفض ومعلومات (Low/Info):** خدمات RTSP، DNS، ومعلومات الإصدارات.
   - تقديم نصائح وحلول علاجية (Remediation Recommendations).
   - احتساب نتيجة أمان عامة من 100.
   - خيارات تصدير بتنسيق نصي (TXT) وجدول بيانات (CSV) ومشاركة مباشرة.

## ⚠️ القيود التقنية لنظام Android

- **أجهزة غير مكسورة الحماية (Non-Rooted):** لا يمكن للتطبيقات العادية إرسال حزم Raw Sockets ICMP مخصصة، لذلك يستخدم التطبيق ملف `/system/bin/ping` مع الاعتماد على مقابس TCP كبديل احتياطي ذكي.
- **جدول ARP على أندرويد 10 فما فوق:** قيّد نظام أندرويد قراءة `/proc/net/arp` لتطبيقات المستخدم لأسباب الخصوصية، لذا يتعامل التطبيق بسلاسة ويعرض البيانات المتاحة مع تنبيه مناسب.
